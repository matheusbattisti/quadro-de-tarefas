# Quadro de Tarefas

Quadro estilo kanban para organizar tarefas em colunas, direto no navegador.

## O que ele faz

- Cartões com prazo e prioridade (alta, média ou baixa).
- Cartões atrasados ficam em destaque, com um contador no topo.
- Cada coluna pode ser ordenada por prazo ou por prioridade.
- Busca e etiquetas para filtrar os cartões.
- Backup: exporte e importe suas tarefas em arquivo.

## Como abrir

É um único arquivo `index.html`, sem dependências. Abra direto no navegador ou acesse pelo GitHub Pages. As tarefas ficam salvas só no navegador de quem usa.
